# AI IT Operations Skills

Reusable Codex skills for evidence-based IT operations, technical support, troubleshooting, and secure repository maintenance.

## English

This collection turns practical IT support and infrastructure experience into reusable AI workflows. The skills favor read-only diagnosis, explicit uncertainty, privacy-conscious evidence, and approval before production changes.

| Skill | Purpose |
|---|---|
| `incident-triage` | Convert incomplete reports into an impact assessment, timeline, hypotheses, safe checks, and escalation summary. |
| `log-analysis` | Correlate application and infrastructure logs without confusing correlation with root cause. |
| `network-diagnostics` | Isolate DNS, routing, TCP, TLS, HTTP, proxy, firewall, and service-reachability failures. |
| `repository-security-audit` | Decide whether a repository is safe and properly attributed before publication or portfolio use. |

Copy the desired folder from `skills/` into your Codex skills directory, then invoke it by name or describe a matching task. Review commands and environment-specific decisions before applying them to production.

## Español

Esta colección convierte experiencia práctica de soporte e infraestructura en flujos reutilizables para IA. Las skills priorizan diagnóstico de solo lectura, incertidumbre explícita, privacidad de la evidencia y autorización antes de realizar cambios productivos.

| Skill | Propósito |
|---|---|
| `incident-triage` | Convierte reportes incompletos en impacto, cronología, hipótesis, verificaciones seguras y un resumen de escalamiento. |
| `log-analysis` | Correlaciona logs de aplicaciones e infraestructura sin confundir correlación con causa raíz. |
| `network-diagnostics` | Aísla fallos de DNS, rutas, TCP, TLS, HTTP, proxy, firewall y disponibilidad de servicios. |
| `repository-security-audit` | Determina si un repositorio puede publicarse y si su autoría está correctamente presentada. |

Copiá la carpeta deseada desde `skills/` al directorio de skills de Codex y luego invocala por nombre o describí una tarea compatible. Revisá los comandos y decisiones específicas del entorno antes de aplicarlos en producción.

## Design principles

- Evidence before conclusions.
- Read-only checks before mutations.
- Minimum necessary access and data collection.
- Clear separation between observation, hypothesis, containment, and remediation.
- Honest attribution and explicit publication gates.
