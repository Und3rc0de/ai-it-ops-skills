# Deployment Readiness / Preparación para despliegues

## English

Produces a go/no-go assessment covering tests, dependencies, secrets, configuration, containers, migrations, health checks, observability, backups, CI/CD, validation, and rollback evidence.

## Español

Produce una evaluación go/no-go que cubre pruebas, dependencias, secretos, configuración, contenedores, migraciones, health checks, observabilidad, backups, CI/CD, validación y evidencia de rollback.

Toolkit command: `ai-it-ops deployment-readiness --input '{"checks":{"tests":true,"rollback":true}}'`
