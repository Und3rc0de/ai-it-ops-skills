# Game Server Operations / Operaciones de servidores de juegos

## English

Designed for ecosystems such as Servers-GX. Correlates launcher, API, authentication, database, host, DNS/TLS, CDN/WAF, deployment, and player-support signals. Restarts, bans, restores, deployments, and announcements always require approval.

## Español

Diseñada para ecosistemas como Servers-GX. Correlaciona launcher, API, autenticación, base de datos, host, DNS/TLS, CDN/WAF, despliegues y soporte a jugadores. Reinicios, bloqueos, restauraciones, despliegues y anuncios siempre requieren autorización.

Toolkit command: `ai-it-ops game-server-ops --input '{"component":"launcher","player_scope":"regional"}'`
