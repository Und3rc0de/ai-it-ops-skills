# Incident Triage / Triaje de incidentes

## English

Turns incomplete incident reports into an impact assessment, provisional severity, timeline, evidence list, ranked hypotheses, safe checks, containment options, and an escalation-ready summary. It favors read-only investigation and requires approval before production changes.

## Español

Convierte reportes incompletos en una evaluación de impacto, severidad provisoria, cronología, evidencia, hipótesis ordenadas, verificaciones seguras, opciones de contención y un resumen listo para escalar. Prioriza investigación de solo lectura y exige autorización antes de cambios productivos.

Toolkit command: `ai-it-ops incident-triage --input '{"impact":"high","urgency":"high"}'`
