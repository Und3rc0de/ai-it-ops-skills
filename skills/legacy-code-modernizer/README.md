# Legacy Code Modernizer / Modernización de código legacy

## English

Builds an incremental modernization roadmap for systems such as PHP or Visual Basic 6. It inventories behavior and ownership, prioritizes characterization tests, identifies migration boundaries, and defines rollout and rollback criteria.

## Español

Construye una hoja de ruta incremental para sistemas como PHP o Visual Basic 6. Inventaría comportamiento y autoría, prioriza pruebas de caracterización, identifica límites de migración y define criterios de despliegue y reversión.

Toolkit command: `ai-it-ops legacy-code-modernizer --input '{"stack":["Visual Basic 6","MySQL"]}'`
