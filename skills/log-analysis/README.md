# Log Analysis / Análisis de logs

## English

Analyzes application and infrastructure logs, masks common secrets, groups repeated signatures, correlates evidence, and avoids presenting temporal proximity as a confirmed root cause.

## Español

Analiza logs de aplicaciones e infraestructura, oculta secretos comunes, agrupa firmas repetidas, correlaciona evidencia y evita presentar proximidad temporal como una causa raíz confirmada.

Toolkit command: `ai-it-ops log-analysis --input '{"lines":["ERROR request 123 failed"]}'`
