# Network Diagnostics / Diagnóstico de redes

## English

Creates a minimally invasive diagnostic path across local configuration, DNS, routing, TCP, TLS, HTTP, proxies, firewalls, and service dependencies. It targets authorized hosts only and never performs broad scanning.

## Español

Crea un recorrido de diagnóstico mínimamente invasivo por configuración local, DNS, rutas, TCP, TLS, HTTP, proxies, firewalls y dependencias. Solo trabaja con destinos autorizados y nunca realiza escaneos amplios.

Toolkit command: `ai-it-ops network-diagnostics --input '{"target":"api.example.test:443"}'`
