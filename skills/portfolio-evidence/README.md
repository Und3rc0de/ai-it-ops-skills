# Portfolio Evidence / Evidencia para portfolio

## English

Turns repository history and project artifacts into defensible CV, GitHub, GitLab, and LinkedIn claims. It distinguishes original work, adaptations, maintenance, collaboration, and third-party foundations while protecting private material.

## Español

Convierte historial y artefactos de proyectos en afirmaciones verificables para CV, GitHub, GitLab y LinkedIn. Distingue trabajo original, adaptaciones, mantenimiento, colaboración y bases de terceros mientras protege material privado.

Toolkit command: `ai-it-ops portfolio-evidence --input '{"authorship":"co-author","evidence":["commits"]}'`
