# Repository Security Audit / Auditoría segura de repositorios

## English

Reviews publication readiness, sensitive filenames, secret exposure risk, attribution, licensing, generated artifacts, dependencies, CI workflows, and history-cleanup requirements without printing secret values or modifying the repository.

## Español

Revisa preparación para publicación, archivos sensibles, riesgo de secretos, atribución, licencias, artefactos generados, dependencias, CI y posibles limpiezas del historial sin mostrar secretos ni modificar el repositorio.

Toolkit command: `ai-it-ops repository-security-audit --input '{"path":"."}'`
