# Publication gates

A repository is not ready for public release when any of the following remains unresolved:

- active or uncertain credentials, private keys, certificates, tokens, or signed configuration;
- customer, employee, patient, account, or other personal data;
- database dumps or production configuration that may contain sensitive values;
- unclear ownership, incompatible license, or missing permission for team/client code;
- malicious or unexpectedly executable artifacts;
- a history that still contains secrets assumed to be removed;
- documentation that materially misrepresents authorship or production readiness.

Repository hygiene findings such as tracked dependencies, build output, caches, oversized binaries, or missing tests may not alone block publication, but they should affect the technical-readiness rating.
