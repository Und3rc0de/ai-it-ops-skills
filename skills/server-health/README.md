# Server Health / Salud de servidores

## English

Evaluates CPU, memory, storage, processes, services, networking, certificates, logs, and missing telemetry. It separates transient spikes from capacity or service failures and never restarts or reconfigures a host automatically.

## Español

Evalúa CPU, memoria, almacenamiento, procesos, servicios, red, certificados, logs y telemetría faltante. Separa picos transitorios de problemas de capacidad o servicio y nunca reinicia ni reconfigura un host automáticamente.

Toolkit command: `ai-it-ops server-health --input '{"metrics":{"disk_percent":92}}'`
