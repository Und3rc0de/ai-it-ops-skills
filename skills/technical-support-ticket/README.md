# Technical Support Ticket / Ticket de soporte técnico

## English

Transforms symptoms or conversations into a sanitized, actionable ticket with priority, category, evidence, a stable duplicate key, next action, customer reply, and escalation notes. It does not submit tickets or messages automatically.

## Español

Transforma síntomas o conversaciones en un ticket sanitizado y accionable con prioridad, categoría, evidencia, clave estable de duplicado, próxima acción, respuesta al usuario y notas de escalamiento. No publica tickets ni mensajes automáticamente.

Toolkit command: `ai-it-ops technical-support-ticket --input '{"component":"api","symptom":"Timeout"}'`
